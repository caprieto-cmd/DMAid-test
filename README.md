# DM.AID TEST 1.8.0

Paquete experimental para GitHub Pages. Subir los archivos a la raíz de `DMAID-Test`.

**Nuevo:** durante el paso de características se muestran los aumentos ASI concedidos por nivel de cada clase, incluidos niveles especiales de Guerrero y Pícaro. Cada aumento distribuye dos puntos, permite +2 en una misma característica o +1/+1, valida máximo 20 y aplica los cambios a la hoja del personaje. La elección alternativa de dotes no se incluye aún.

Las campañas TEST utilizan almacenamiento separado. Exportar respaldos antes de actualizar.
